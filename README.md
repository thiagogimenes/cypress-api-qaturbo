# Projeto de automação de API 

Projeto de automação de api usando cypress

Ref. Bootcamp qazando


### Pré-requisitos
- nodejs instalado 
- vscode instalado
	- editor de código

Criar pasta e abrir no vsCode

- criar projeto -> npm init -y
- instalar cypress -> npm install cypress
	- add sessão de dependências
	- criou o package-lock
	- criou o node modules
- Iniciar cypress para configurar -> npx cypress open
- criar aquivo de teste
- criar cenário (estrutura do arquivo de teste).
